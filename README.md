# SportLog — Legal

Public legal documents for the **SportLog** iOS app.

| Document | URL |
| --- | --- |
| Privacy Policy | https://shreyasb1.github.io/sportlog-legal/ |

This repository is public solely so the App Store can reach these pages at a
stable URL. The SportLog application source lives in a separate private
repository.

## Updating

The canonical copy of the privacy policy lives at `docs/privacy-policy.html` in
the SportLog app repo. When it changes, copy it here to both `index.html` and
`privacy-policy.html`, then commit and push — GitHub Pages redeploys
automatically within a minute or so.

Remember to bump the "Last updated" date in the document itself.
